# Assets

Questa cartella contiene asset statici pubblici riutilizzabili nel materiale del corso, ad esempio:

- diagrammi;
- immagini create per le lezioni;
- screenshot sanitizzati;
- icone o schemi con licenza compatibile;
- file di supporto non sensibili.

Non inserire:

- screenshot con dati personali;
- credenziali o token;
- evidenze reali di clienti;
- materiale riservato d'esame;
- contenuti per i quali non esistono diritti o licenze adeguati.
