# Lessons

Questa cartella raccoglierà il materiale delle singole lezioni.

## Convenzione proposta

```text
lessons/
├── 00-baseline-and-mindset/
├── 01-vapt-engagement/
├── 02-technical-foundations/
├── 03-recon-enumeration/
├── 04-vulnerability-assessment/
├── 05-web-pentesting-foundations/
├── 06-web-injection/
├── 07-auth-api-security/
├── 08-controlled-exploitation/
├── 09-post-exploitation/
├── 10-reporting/
├── 11-ai-assisted-pentesting/
└── 12-capstone/
```

Il numero finale di moduli dipenderà dal monte ore disponibile; la numerazione può quindi cambiare.

## Contenuto minimo di una lezione

Ogni cartella dovrebbe poter contenere:

- `README.md` — obiettivi, scaletta e materiale testuale;
- `slides/` — eventuali sorgenti o export delle slide;
- `demo/` — file necessari alle demo;
- collegamenti ai laboratori in `labs/`;
- esercizi pubblici e homework, quando previsti.

## Struttura suggerita del README della lezione

1. Obiettivi di apprendimento
2. Prerequisiti
3. Concetti chiave
4. Demo
5. Laboratorio
6. Challenge / Hard mode
7. Evidenze da raccogliere
8. Collegamento al report
9. Riferimenti
10. Checklist di fine lezione

## Nota

Non usare questa cartella per materiale d'esame riservato. Vedi [`../docs/REPOSITORY_POLICY.md`](../docs/REPOSITORY_POLICY.md).
