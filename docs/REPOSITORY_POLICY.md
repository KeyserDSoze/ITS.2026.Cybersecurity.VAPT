# Repository Policy

Questa repository contiene materiale pubblico per il corso ITS Umbria 2026 — Vulnerability Assessment & Penetration Testing.

## Contenuti ammessi

Sono ammessi:

- materiale teorico delle lezioni;
- laboratori destinati agli studenti;
- setup degli ambienti didattici;
- challenge pubbliche e relative istruzioni;
- template di report e finding;
- riferimenti, checklist e cheat sheet destinati alla classe;
- codice o configurazioni di ambienti volutamente vulnerabili destinati alla didattica.

## Contenuti da non pubblicare

Non devono essere inseriti in questa repository:

- testi di prove d'esame non ancora svolte;
- soluzioni o walkthrough di prove valutative;
- flag, password, token o credenziali usate per una prova;
- rubriche di valutazione che si desidera mantenere riservate;
- configurazioni che rivelino in anticipo la soluzione di un esame;
- dati personali o reali di studenti, docenti o terzi;
- segreti applicativi, API key o credenziali reali.

## Branch e riservatezza

La repository è pubblica. Un branch di una repository pubblica non costituisce un'area privata: contenuti committati su qualsiasi branch possono essere visibili e recuperabili.

Il materiale d'esame riservato dovrà quindi essere conservato:

1. fuori da GitHub; oppure
2. in una repository GitHub separata e privata.

## Regola operativa per l'esame

Fino a esplicita decisione del docente, **non creare cartelle `exam`, `exams`, `assessment-final`, `solutions` o equivalenti contenenti materiale valutativo riservato**.

Dopo lo svolgimento di una prova, il docente potrà decidere se pubblicare una versione sanitizzata come esercizio o write-up.

## Sicurezza dei laboratori

Ogni esercizio offensivo deve essere concepito per sistemi propri, target volutamente vulnerabili o infrastrutture per cui esista autorizzazione esplicita. Le istruzioni devono indicare chiaramente lo scope del laboratorio quando questo non è ovvio.
