## Materiale d'esame

La progettazione può essere annotata privatamente dal docente, ma **nessun artefatto riservato dell'esame deve essere prodotto o conservato in questa repository pubblica**.

Quando verrà avviata la progettazione dell'esame, usare un workspace locale o una repository privata separata.
