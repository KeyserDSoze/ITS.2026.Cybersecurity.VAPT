# UmbraMarket — Estratto calendario operativo

> Informazioni fornite per il planning dell'engagement. Scenario fittizio.

## Settimana tipo

| Giorno | Evento ricorrente |
|---|---|
| Lunedì | volume consegne alto al magazzino |
| Martedì | due commerciali spesso fuori sede |
| Mercoledì 09:30 | riunione commerciale |
| Giovedì | due commerciali spesso fuori sede |
| Venerdì | attività amministrative di chiusura settimana |

## Orari indicativi

| Fascia | Attività |
|---|---|
| 07:45–08:30 | avvio magazzino / prime consegne |
| 08:30–09:00 | ingresso principale uffici |
| 10:15–10:45 | pausa di metà mattina |
| 12:30–14:00 | pausa pranzo a turni |
| 17:30–18:30 | uscita progressiva uffici |

## Eventi straordinari

- una fiera commerciale è prevista il mese prossimo;
- un nuovo commerciale dovrebbe iniziare nelle prossime settimane;
- il progetto interno “Orvieto” compare in alcuni calendari, senza ulteriori dettagli;
- l'IT effettua occasionalmente manutenzioni dopo le 18:00.
