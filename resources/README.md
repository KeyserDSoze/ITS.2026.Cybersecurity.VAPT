## Vulnerability Intelligence

Quando si analizza una vulnerabilità nota, verificare preferibilmente più fonti, ad esempio:

- advisory del vendor;
- record CVE;
- NVD o fonti equivalenti;
- repository ufficiale del progetto;
- eventuali advisory CERT/CISA o di soggetti autorevoli.

Uno snippet trovato online o una risposta AI non costituiscono da soli una verifica affidabile.

## Regola per le fonti

Durante il corso gli studenti dovrebbero imparare a distinguere:

1. fonte primaria;
2. fonte secondaria autorevole;
3. blog/write-up;
4. output di scanner;
5. contenuto generato da AI.

Più una decisione ha impatto, più è importante risalire a fonti primarie e verificabili.
